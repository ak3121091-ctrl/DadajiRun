DADAJI'S IMPOSSIBLE SCHOOL JOURNEY — VISUAL UPGRADE V3

WHAT CHANGED
- Added layered low-poly mountain ranges for a stronger sense of distance.
- Added six looping river sections on both sides of the road with water glints and subtle movement.
- Added palm trees, village fence sections, straw stacks and extra rural silhouettes.
- Improved runner animation with torso/head counter-sway and a more expressive bicycle lean.
- Added an obstacle warning pill that identifies the upcoming obstacle and lane, becoming more urgent as it approaches.
- Added lightweight procedural bird-like ambience and occasional bicycle-bell-like chimes after audio is enabled.
- Added responsive styling for the warning indicator and reduced-motion support.

RUN
1. Extract the ZIP.
2. Open Game/index.html in a modern browser with internet access (Three.js is loaded from a CDN).
3. Click START THE JOURNEY. If opening the file directly is blocked by your browser, run a local static server from the Game folder, for example: python -m http.server 8000, then visit http://localhost:8000.

CONTROLS
- Left/Right arrows or A/D: change lanes
- Up/Space/W: jump
- Down/S: slide
- P/Escape: pause
- On touchscreens: swipe or use the on-screen buttons

TESTING NOTE
Node.js syntax check passed during packaging. This is not a substitute for full browser testing on desktop and mobile. Verify obstacle warning timing, collision fairness, rendering performance and sound balance in your browser.
